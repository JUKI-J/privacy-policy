TimerLync 개인정보처리방침

시행일: 2026년 7월 27일

TimerLync("앱", "저희")는 setlog.net의 개발자가 개발·운영합니다.

TimerLync는 여러 기기가 같은 카운트다운을 공유하는 무료 타이머 앱입니다. 계정, 광고, 인앱 구매가 없습니다. 본 개인정보처리방침은 앱이 수집하는 정보의 범위, 이용 목적 및 이용자의 권리를 설명합니다.

수집하는 정보

TimerLync는 카운트다운 공유에 필요한 최소한의 정보만 수집합니다. 룸을 만들거나 참가하기 전까지는 수집되는 정보가 없습니다.

기기 식별자(UUID)

  • 수집 항목: 앱이 최초 실행 시 무작위로 생성하는 UUID(A1B2C3D4-E5F6-... 형태의 고유 문자열). Apple ID·광고 식별자나 Apple이 부여한 식별자가 아니며, 앱을 삭제 후 재설치하면 새 값으로 바뀝니다.
  • 수집 목적: 룸 안에서 귀하의 기기를 식별해 올바른 카운트다운을 전달하고, 참가자를 서로 구분하기 위함
  • 보유 기간: 룸이 활성인 동안 기기 UUID는 참가자 식별과 타이머 메시지 전달을 위해 중계 서버(Cloudflare)의 임시 세션 상태에 보관되며, 룸 종료 시 삭제됩니다. 별도의 서버 로그·분석·영구 보존은 하지 않습니다.

표시 이름

  • 수집 항목: 룸에서 귀하의 기기 옆에 표시되는 이름입니다. 닉네임을 설정하지 않았다면 기기의 모델명이 사용되며, iOS 17 이상에서는 별도 엔타이틀먼트가 없는 앱에 개인화된 이름 대신 일반 모델명(대개 "iPhone" 또는 "iPad")이 제공됩니다. 설정에서 닉네임을 직접 입력하면 그 문자열이 대신 사용되므로, 같은 룸의 다른 참가자에게 보이길 원하지 않는 내용은 입력하지 마시기 바랍니다.
  • 수집 목적: 세션 중 다른 참가자가 기기를 구분할 수 있도록 다른 참가자 기기로 전송·표시됩니다.
  • 보유 기간: 위 기기 UUID와 동일하게 룸이 활성인 동안에만 임시 세션 상태에 보관되며, 룸 종료 시 삭제됩니다.
  • 열람 범위: 룸은 짧은 룸 코드로 식별되며 중계 서버는 코드를 가진 사람이 누구인지 확인하지 않습니다. 즉 룸 코드를 알게 된 사람은 그 룸에 참가할 수 있고, 참가자들의 표시 이름을 보게 됩니다. 룸 코드는 회의 링크처럼 다루어 세션에 참여시킬 사람에게만 공유하시기 바랍니다.

카운트다운 데이터

  • 수집 항목: 카운트다운의 종료 시각과 이를 변경하는 제어 이벤트(시작·일시정지·재개·시간 추가 등)
  • 수집 목적: 모든 기기가 같은 카운트다운을 유지하게 하는 공유 상태입니다.
  • 보유 기간: 참가자 간 중계될 뿐 서버에 저장되지 않습니다.

근처 기기로 광고되는 룸 정보

  • 수집 항목: 룸을 호스팅하는 동안 앱은 블루투스·Wi-Fi와 로컬 네트워크로 룸을 광고합니다. 광고에는 룸 코드, 호스트의 표시 이름, 참가자 수, PIN 필요 여부, 프로토콜 버전이 담기며 기기 식별자는 포함되지 않습니다.
  • 수집 목적: 옆에 있는 사람이 아무것도 입력하지 않고 룸을 찾아 참가할 수 있게 하기 위함
  • 보유 기간: 호스팅하는 동안에만 광고되며 저장되지 않습니다. 다만 룸을 탐색 중인 근처 기기는 참가 전에도 이 광고를 볼 수 있습니다 — 모든 플랫폼의 근거리 탐색이 동작하는 방식입니다.

IP 주소

  • 수집 항목: 원격 중계를 사용하는 경우에 한해, 접속한 IP 주소
  • 수집 목적: 호스팅 제공자가 연결을 전달하는 데 필요하며, 한 곳에서 무제한으로 룸을 만들거나 참가하지 못하도록 하는 오남용 방지 카운터로 잠시 사용합니다.
  • 보유 기간: 오남용 방지 카운터는 약 1분 후 만료됩니다. 기기 식별자·표시 이름·특정 룸과 연결되지 않습니다.

수집하지 않는 정보

TimerLync는 다음 정보를 수집·저장·처리하지 않습니다.

  • 이름, 이메일 주소, 전화번호 등 개인 식별 정보
  • Apple ID 또는 기타 계정 정보 — 앱에 로그인 자체가 없습니다
  • 위치 데이터(GPS 또는 네트워크 기반)
  • 연락처 또는 주소록
  • 브라우징 이력 또는 크로스앱 사용 추적 정보
  • 광고 식별자(IDFA)
  • 건강·피트니스 데이터
  • 금융 또는 결제 정보 — TimerLync는 무료이며 인앱 구매가 없습니다

타사 분석·광고·성과측정·크래시 리포팅 SDK를 일절 사용하지 않습니다. 앱은 이용자를 프로파일링하거나 다른 앱·웹사이트에서의 활동을 추적하지 않습니다.

앱이 요청하는 권한

  • 카메라 — QR 코드로 룸에 참가할 때만 사용합니다. 코드를 읽기 위해 기기 안에서 처리하며, 사진이나 영상은 저장하지도 전송하지도 않습니다.
  • 로컬 네트워크 — 같은 Wi-Fi에 있는 기기가 연 룸을 찾아 연결하기 위함
  • 블루투스 — 같은 Wi-Fi에 있지 않은 근처 기기와 연결하기 위해 근거리 연결이 사용합니다.
  • 알림 — 앱이 백그라운드에 있거나 연결이 끊겨도 00:00:00에 알람이 울리도록 합니다. 알림은 기기에서 예약됩니다.

기기 간 연결 방식

TimerLync는 가능한 한 근거리에서 동기화하고, 필요할 때만 인터넷 경로로 넘어갑니다.

  • 근거리 연결(블루투스·Wi-Fi): 기기 간 직접 연결이며 전송 구간이 암호화됩니다. 저희 서버를 거치지 않습니다.
  • 로컬 네트워크 연결: 같은 네트워크의 기기 사이에서 쓰는 더 빠른 직접 경로입니다. 이 경로는 암호화되지 않으므로, 해당 네트워크의 트래픽을 관찰할 수 있는 사람은 룸 코드·표시 이름·타이머 이벤트를 볼 수 있습니다. PIN으로 보호된 룸에서는 앱이 이 경로를 사용하지 않습니다.
  • 원격 중계: 기기가 서로 멀리 있을 때 사용하며 전송 구간이 암호화(TLS)됩니다.

Apple Watch

Apple Watch 앱을 사용하는 경우, iPhone이 현재 카운트다운의 종료 시각과 기본 룸 정보를 페어링된 본인의 워치로 전달합니다. iPhone이 사정권 밖일 때는 워치가 직접 중계 서버에 연결할 수 있으며, 이때 워치에서 생성된 별도 식별자를 사용합니다. 이 식별자는 위에서 설명한 iPhone 기기 식별자와 동일하게 취급됩니다.

제3자 서비스

저희는 귀하의 데이터를 어떠한 제3자에게도 판매·임대·공유하지 않습니다.

Cloudflare는 원격 룸 동기화에 사용되는 중계 서버(timerlync-api.setlog.net)를 운영합니다. 룸 상태(기기 식별자·표시 이름·룸 설정)는 룸이 활성인 동안에만 Cloudflare 세션 스토리지에 보관되고 룸 종료 시 삭제되며, 동기화 메시지는 참가자 간 중계될 뿐 보존되지 않습니다. 기기 식별자와 표시 이름은 요청 주소가 아니라 요청 헤더로 전송되고 애플리케이션 요청 로깅은 꺼져 있으므로, 저희 로그에 기록되지 않습니다. 다만 인프라 제공자인 Cloudflare는 트래픽 전달을 위해 IP 주소 등 연결 메타데이터를 불가피하게 처리합니다. Cloudflare의 개인정보 처리는 Cloudflare 개인정보 처리방침에 따릅니다.

Apple 시간 서버(time.apple.com)에 기기 시계 보정을 요청합니다. 모든 기기가 정확히 같은 순간에 0에 도달하게 하는 것이 이 보정입니다. 표준 네트워크 시간 요청으로 타임스탬프만 주고받으며 앱의 어떤 식별자도 포함하지 않습니다.

기기 로컬 저장 데이터

다음 정보는 기기에만 저장되며 어떠한 서버에도 업로드되지 않습니다.

  • 타이머 프리셋, 저장한 시퀀스, 그리고 직접 입력한 단계 이름
  • 완료된 타이머의 세션 기록
  • 앱 설정, 닉네임, 위에서 설명한 기기 식별자
  • 진행 중이던 세션의 스냅샷 — 중단된 타이머를 다음 실행 때 복원 제안하기 위해 저장합니다. 룸에 참여 중이라면 이 스냅샷에는 해당 룸의 참가자 목록(기기 식별자·표시 이름)과, 룸에 PIN이 설정돼 있다면 그 PIN이 포함됩니다. 룸을 나가면 삭제됩니다.

프리셋과 세션 기록은 앱 안에서 언제든지 삭제할 수 있고, 앱을 삭제하면 전부 함께 사라집니다. 다른 앱 데이터와 마찬가지로 이 파일들은 기기의 암호화 백업에 포함될 수 있습니다.

아동의 개인정보 보호

TimerLync는 만 13세 미만 아동의 정보를 의도적으로 수집하지 않습니다. 앱에는 아동을 대상으로 하는 기능이 포함되어 있지 않습니다.
